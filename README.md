# 뭐해요? · What Are You Doing?

부모의 생활 정보를 짧은 안부 메시지로 전달해, 자녀가 자연스럽게 연락할 계기를 만드는 프로토타입입니다.

**Flutter · FastAPI · ESP32 · Ollama**

## 문제와 접근

떨어져 지내는 가족이 매번 특별한 이유가 있어야 연락하는 것은 아닙니다. ‘뭐해요?’는 센서로 들어온 생활 신호를 요약하고, 자녀가 가볍게 안부를 물을 수 있도록 돕는 서비스를 구상하며 시작했습니다.

센서 신호만으로 실제 행동이나 건강 상태를 확정하지 않습니다. 생활 정보는 당사자의 동의를 전제로 다뤄야 하며, 이 저장소는 의료·안전 모니터링 제품이 아닌 개발용 프로토타입입니다.

## 구성

```text
ESP32 센서 또는 합성 데모 이벤트
          ↓
FastAPI: 이벤트 저장 → 오늘 기록 분석 → 최근 기록과 비교
          ↓
Ollama: 분석 내용을 짧은 안부 메시지로 작성
          ↓
Flutter: 메시지 확인 및 설정된 번호로 전화 연결
```

| 폴더 | 내용 |
| --- | --- |
| `app/` | Flutter 앱과 플랫폼별 기본 구성 |
| `server/` | FastAPI API, 생활 이벤트 분석, 합성 데모 데이터 입력 |
| `firmware/esp_what_are_you_doing/` | ESP32 스케치와 비밀 설정 예시 |

## 담당한 일과 AI 활용

- 서비스 방향과 구현 요구사항을 구체화하고 앱·서버·센서 연동을 시험했습니다.
- 최소 기능부터 구현하고, 데모 입력과 실제 센서 이벤트를 구분하는 방향으로 개발을 진행했습니다.
- ChatGPT를 기획, 코딩, 오류 원인 확인과 구현 과정 정리에 활용했습니다.
- 서비스 내부의 메시지 생성은 로컬 Ollama 모델을 사용합니다. ChatGPT 개발 보조와 OpenAI API 사용은 별개의 사항입니다.

학생들과의 프로젝트 진행 맥락을 포함하며, 이 저장소를 단독 개발 실적이나 모든 구성요소의 독점 저작권 주장으로 제시하지 않습니다. DailyCare와는 별개 프로젝트입니다.

## 로컬 실행

Python 3.10 이상, 프로젝트의 `pubspec.yaml` SDK 조건을 충족하는 Flutter, 선택한 모델을 실행할 수 있는 Ollama 환경이 필요합니다. 예시 모델은 `exaone3.5:7.8b`이며 사용 전 해당 모델의 조건과 장비 요구사항을 확인하세요.

서버:

```powershell
cd server
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo_data.py
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8001
```

`demo_data.py`는 실행일 기준 합성 이벤트를 추가합니다. 새 데모 환경에서 사용하세요. 저장된 실제 센서 기록은 이 저장소에 포함하지 않았습니다.

Ollama가 실행 중인 별도 터미널에서:

```powershell
ollama pull exaone3.5:7.8b
```

다른 터미널에서 앱 실행(Windows 데스크톱 예시):

```powershell
cd app
flutter pub get
flutter run -d windows --dart-define=API_URL=http://127.0.0.1:8001/today-message
```

Android 에뮬레이터에서는 PC 서버 주소를 `http://10.0.2.2:8001/today-message`로 전달합니다. 실제 휴대폰·ESP32에서는 같은 사설 네트워크의 PC 주소를 사용해야 합니다. 기본 플랫폼 템플릿에서 모바일 HTTP 허용·권한 설정을 추가해야 할 수 있습니다. 모바일 릴리스 빌드는 이번 정리 과정에서 검증하지 않았습니다.

전화 기능은 `--dart-define=PARENT_PHONE=...`로 본인이 허락받은 번호를 설정한 경우에만 연결을 시도합니다. 코드에 개인 번호를 저장하지 마세요.

ESP32:

1. `secrets.example.h`를 같은 폴더의 `secrets.h`로 복사합니다.
2. 본인의 Wi-Fi와 PC 주소를 입력합니다. 이 파일은 Git에서 제외됩니다.
3. Arduino IDE에서 스케치를 열고 ESP32 보드 환경에서 업로드합니다.
4. 같은 신뢰할 수 있는 사설망에서 테스트할 때만 서버 바인딩과 방화벽을 조정합니다. 공개 인터넷에 노출하지 마세요.

서버 설정은 `OLLAMA_URL`, `OLLAMA_MODEL`, `DATA_FILE` 환경변수로 변경할 수 있습니다.

## 현재 구현과 한계

- 이벤트 입력·저장, 최근 최대 7일 기록 관리, 일일 분석·비교, 메시지 요청, 전화 연결 UI가 코드에 구현되어 있습니다.
- 센서 이벤트 이름 중 `bed_pressure` 등은 논리적 분류이며, 현재 스케치는 초음파·PIR·버튼 신호를 대응시킵니다. 실제 압력 센서 측정으로 오해하면 안 됩니다.
- 평균 계산, 활동 추정과 예외 처리에는 개선이 필요합니다. 특히 데이터가 적거나 모델 호출이 실패한 경우 생성 문장을 실제 상태로 믿어서는 안 됩니다.
- API 인증, 접근 제어, 영속 데이터베이스, 배포용 보안 설정은 갖추지 않았습니다. 단일 사용자 로컬 데모 용도입니다.
- 하드웨어와 모델을 포함한 전체 동작을 이번 업로드 준비 과정에서 재검증하지 않았습니다.
- 사용자 실험, 연락 증가 효과, 만족도, 임상적 성능을 검증했다는 주장은 하지 않습니다.

## 업로드용 정리

기존 바탕화면 원본은 변경하지 않았습니다. 업로드용 사본에서 Wi-Fi·개인 PC 주소를 설정값으로 분리하고, 센서 기록·캐시·압축파일·개인 서류를 제외했습니다. ESP32의 서버 포트를 이 프로젝트의 `8001`로 맞추고, 합성 데모 날짜를 실행일 기준으로 바꿨습니다.

새로운 오픈소스 라이선스를 부여하지 않았습니다. 외부 패키지·생성된 플랫폼 구성·모델에는 각자의 이용 조건이 적용됩니다.
